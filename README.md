# Date Ideas

Find a place for your next special moment.

## Overview

Date Ideas is a React Native mobile app for discovering places
for first dates, anniversaries, and quality time together.

Users will be able to search by city, choose a date category,
browse places, and view venue details using live Yelp API data.
- Browse photos, ratings, and prices when available.
- View venue addresses and available contact information.
- Open a venue's Yelp page.
- Display loading, error, and empty-result messages.

## Planned Screens

1. Find Your Date Idea — enter a city and select a category.
2. Places for Two — browse matching venues.
3. Your Next Date — explore a selected venue's details.

## Planned Technologies

- React Native and Expo
- React Navigation
- Axios with async/await
- React Hooks
- FlatList
- StyleSheet and Flexbox
- Expo Vector Icons
- Yelp API
- Postman for API testing

## Data Source

Venue information will be retrieved live from Yelp API.
No local business dataset or database will be used.

API access and available fields will be verified during development.
API credentials will not be committed to this repository.
